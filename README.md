⚡ Insight-CLI
Stop opening heavy Jupyter Notebooks just to see what's inside a CSV. Insight-CLI is a lightweight, blazing-fast command-line tool that instantly generates a beautiful data profile for any dataset.

Python VersionLicense

✨ Features
Instant Profiling: Get column types, missing percentages, and unique value counts in milliseconds.
Beautiful Output: Built with rich for a highly readable, color-coded terminal table.
Zero Configuration: Just point it at a file. No complex setup required.
🚀 Installation
Clone this repository:
git clone https://github.com/Tharunkumararela/Insight-CLI.gitcd Insight-CLI
Install dependencies:
bash

pip install -r requirements.txt
💻 Usage
Run the script and pass the path to any CSV file:

bash

python insight.py your_dataset.csv
